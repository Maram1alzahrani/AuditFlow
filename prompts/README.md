# AI Prompt Log

AI assistance was used interactively. The files in this directory preserve the
task prompts, constraints, and important follow-up iterations that materially
changed the solution. Generated code was not accepted solely because it ran:
every stage was compiled, executed against the full repository, checked against
contract pages or source records, and covered by deterministic tests.

The prompts are normalized for readability from the working conversation; no
claim is made that every conversational message is reproduced verbatim.
